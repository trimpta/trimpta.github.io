LabChat

A zero-dependency Python terminal chat application for local networks.

Features

  • Zero external dependencies
  • Single Python file
  • Linux + Windows
  • LAN discovery
  • Automatic subnet scanning
  • Direct IP connection
  • Configurable port
  • Terminal UI
  • Peer-to-peer architecture

Requirements

Python 3.9+
A local network connection

Run

Linux:

python3 labchat.py

Windows:

python labchat.py

First Run

On your first run, the application will ask for a display name. This name is saved locally so you don't have to enter it every time. You can change it later using the /name command.

Discovery

LabChat uses UDP broadcast to automatically discover other instances on the same local network. It also supports explicit subnet scanning using the /scan command, which will automatically check all IPs in your local /24 subnet for running LabChat instances.

Manual Connection

If discovery fails (due to firewalls or network isolation), you can connect directly to another user if you know their IP address:

/connect 192.168.0.121:50555

Troubleshooting

  • Discovery doesn't work: UDP broadcasts may be blocked by your router, or devices might be on different subnets. Try /scan instead.
  • Cannot connect: Windows Firewall might be blocking incoming connections to port 50555. You may need to allow Python through the firewall.
  • Wi-Fi Client Isolation: Public or university Wi-Fi networks often prevent devices from talking directly to each other. In this case, LabChat will not work.
  • Wrong Subnet: If your network uses a mask other than /24 (e.g. 255.255.255.0), the automatic scan might not check the correct IP range.
